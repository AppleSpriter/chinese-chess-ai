# 中国象棋 AI 对弈

一个零依赖的浏览器版中国象棋项目，支持本地对弈、AI 自动应手、AI 走法对照，以及随每一步更新的右侧实时胜率。

## 运行

直接打开 `index.html` 即可使用。也可以在本目录启动静态服务器：

```bash
npm run dev
```

然后访问 `http://localhost:5173`。

## 功能

- 完整棋盘与基础中国象棋合法走法
- 将军、飞将、蹩马腿、塞象眼、炮架等规则判定
- 人机对弈，可选择 AI 执红或执黑
- AI 难度：入门、普通、困难、大师
- AI 深度 1-4 档，可随时让 AI 走当前一手
- 右侧实时胜率、局面分数和前三条候选走法
- 棋谱记录、悔棋和翻转棋盘

## AI 逻辑

AI 使用 minimax + alpha-beta 剪枝搜索。困难和大师档会启用置换表缓存与关键吃子延伸，减少浅层搜索导致的明显漏算；入门和普通档会在候选好棋中加入少量随机性，让难度更有区分。
